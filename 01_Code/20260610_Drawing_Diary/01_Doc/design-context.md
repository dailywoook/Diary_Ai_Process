## 디자인 목표

"쓰고 싶다"는 감각을 만드는 것이 최우선. 기능을 나열하는 앱이 아니라, 종이 일기장을 꺼내는 것처럼 친근하고 따뜻한 경험.

## 디자인 방향 (무드)

- **아날로그 감성 + 미니멀** — 종이 질감, 손 글씨 느낌, 연필·잉크 뉘앙스
- **조용하고 차분함** — 과한 채도나 그림자 없이 여백 중심
- **모바일 퍼스트** — 360px 기준, 터치 친화적 UI
- 앱 무드 레퍼런스: 종이 다이어리, Field Notes 노트북, Bear 앱

## 컴포넌트 정의

### 날짜 바 (Date Bar) — 읽기 상태 상단
- 높이 48px, 배경 크림
- 좌: `<` 버튼 (이전 날짜), 우: `>` 버튼 (다음 날짜, 오늘 이후면 비활성)
- 중앙: 날짜 텍스트 (예: "2026년 6월 10일")
- 버튼 탭 영역: 최소 44×44px

### 편집 바 (Edit Bar) — 편집 상태 상단
- 높이 48px
- 좌: "취소" 텍스트 버튼 (액센트 색), 중앙: 날짜 (소형), 우: "저장" 텍스트 버튼 (액센트 색, bold)
- 취소 동작:
  - 변경 없음(편집 진입 후 아무것도 그리지 않은 경우): 즉시 읽기 모드로 복귀.
  - 변경 있음(획 1개 이상 그리거나 오브젝트 추가·이동한 경우): 확인 다이얼로그 표시.
    - 다이얼로그 문구: "변경 사항을 버릴까요?"
    - 버튼: "계속 편집" (취소, secondary) / "버리기" (확인, danger 색)
    - "버리기" 탭 시 마지막 저장본으로 복원 후 읽기 모드 복귀.

### 캔버스 (Canvas)
- 배경: 흰색 또는 아주 연한 크림 (`#FEFCF9`)
- 테두리: 없음 (배경과 구분은 미세한 그림자로)
- 렌더링 해상도: `devicePixelRatio × 논리 크기` (Retina 대응). 논리 크기 = 화면 폭 × (화면 높이 - 104px). CSS 크기는 논리 크기 고정, canvas width/height는 ×devicePixelRatio.
- 저장 방식: **IndexedDB** (PRD 7항 결정). localStorage 사용 금지 (5MB 한계).
  - DB명: `drawing-diary-db` / 스토어명: `entries`
  - 레코드 키: `"YYYY-MM-DD"` (예: `"2026-07-06"`)
  - 레코드 구조:
    ```json
    {
      "date": "2026-07-06",
      "canvasPng": "<base64 PNG 문자열>",
      "objects": []
    }
    ```
  - `canvasPng`: `canvas.toDataURL("image/png")` 결과값. 날짜 단위로 덮어쓰기 저장.
  - `objects`: 현재 MVP 범위에서 빈 배열로 고정 (사진·텍스트 오브젝트는 캔버스에 합성 후 PNG로 통합 저장).
- 빈 상태: 중앙에 안내 문구 + 흐린 연필 아이콘 (`pen-line`, 색상 `#C4BFB8`)
  - 문구: "오늘을 기록해보세요"

### 하단 액션 바 — 읽기 상태
- 높이 56px
- 좌: "편집" 버튼 (기록 없을 시 "기록 시작") / 이전 날짜 페이지에서는 편집 버튼 숨김
- 우: "공유" 버튼 — 기록 없을 시 `#C4BFB8`로 비활성 표시 (버튼은 보이되 탭 무반응)
- 버튼 스타일: 아웃라인(테두리 있는 보조 버튼) 또는 텍스트 버튼

### 사진 삽입 (도구 모음 [사진] 버튼)
- MVP 범위: `<input type="file" accept="image/*">` 방식으로 기기 앨범 선택만 지원.
- 카메라 촬영 직접 지원(`capture="environment"`)은 MVP에서 제외. 기기 앨범 선택 후 카메라로 전환하는 것은 OS가 알아서 처리.
- 선택한 이미지는 canvas 위에 오브젝트로 삽입 (드래그 이동 가능, 핀치 리사이즈는 MVP 제외).

### 도구 모음 — 편집 상태 하단
- 높이 56px
- 아이콘 버튼 5개: [↩] [펜] [지우개] [T] [사진]
- 편집 모드 진입 시 기본 활성 도구: 펜
- 활성 도구: 아이콘 배경에 연한 액센트 원형 표시
- 간격: 균등 분배

### 색상·굵기 서랍 (Drawer) — 펜 선택 시
- 도구 모음 위로 슬라이드해서 열림
- 색상 원형 버튼 8개 (직경 28px, 간격 8px)
  - 확정 팔레트 (채도 낮춘 머티드 톤 채택 — 아날로그 감성에 맞게):
    | 이름 | 헥스값 |
    |------|--------|
    | 검정 | `#1A1A1A` |
    | 회색 | `#6B6B6B` |
    | 로즈레드 | `#B87870` |
    | 테라코타 | `#C09070` |
    | 옐로오커 | `#C4AF70` |
    | 세이지 | `#7BAA8A` |
    | 더스티블루 | `#7090B8` |
    | 라벤더 | `#9080B8` |
  - 선택된 색상: 외곽 링 (`#6B4F3A`, 3.5px) 으로 표시
- 굵기 슬라이더: 2px ~ 20px 범위, 기본값 4px
- 배경: 흰색, 상단에 미세한 구분선

### 텍스트 오브젝트 (Text Object)
- 구현 방식: canvas 위 HTML 오버레이 (`<div contenteditable>`)로 입력받고, 확정 시 canvas에 `fillText()`로 렌더링
- 기본 스타일: 크기 16px, 색상 `#1A1A1A`, 굵기 400
- 입력창 크기: 최소 120px 폭, 내용에 따라 자동 확장
- 한글 IME 가드: `keydown` 이벤트에 `if (e.isComposing) return;` 적용 (Enter로 입력 확정 시 중복 방지)
- **XSS 방지**: 텍스트 확정 시 반드시 `element.textContent` (또는 `innerText`)로 값을 추출해 `fillText()`에 전달. `innerHTML` 직접 파싱 금지.
- 확정 방법: 오브젝트 외부 탭 시 `blur` 이벤트로 자동 확정. 또는 도구 모음 "완료" 버튼 탭.

### 공유 시트 (Bottom Sheet)
- 하단에서 슬라이드업
- 뒤 캔버스: 반투명 딤 (`rgba(0,0,0,0.28)`)
- 시트 배경: 흰색, 상단 모서리 16px 반경
- 내부 버튼: "이미지로 저장 (PNG)" (primary 스타일), "닫기" (secondary)

### 오브젝트 핸들 (Object Handle)
- 선택된 사진/텍스트 오브젝트 테두리: 점선 (`#6B4F3A`, 1.5px dash)
- 모서리 핸들: 흰 원 + 액센트 테두리, 직경 16px
- 도구 모음 자리에 "삭제" / "완료" 버튼으로 교체

### 토스트 메시지
- 하단 중앙, 반투명 어두운 배경 (`rgba(26,26,26,0.70)`)
- 자동 2초 후 사라짐
- 성공 예: "저장되었습니다", "이미지가 저장되었습니다"
- 오류 예: "저장에 실패했습니다. 브라우저 저장공간을 확인해주세요"
  - 오류 토스트: 배경 `--color-danger` 계열 (`rgba(217,79,61,0.88)`), 자동 4초 후 사라짐

## 인터랙션 원칙

- 모든 탭 가능 요소: 최소 44×44px 터치 영역. 버튼 시각 높이가 44px 미만인 경우(예: 36px 아웃라인 버튼) `min-height: 44px` 또는 투명 padding으로 실제 터치 영역을 44px 이상 보장.
- 버튼 hover·pressed 상태: 프로토타입 단계에서 구현 생략 (기본 상태만 구현).
- 서랍·시트 열기: ease-out 200ms
- 페이지 전환: 좌우 슬라이드 (300ms ease-in-out), 또는 즉시 전환 (스와이프 시)
  - 스와이프 임계값: 50px 이상 수평 드래그 시 전환 (미만이면 원위치)
  - 왼쪽 스와이프 → 다음 날짜, 오른쪽 스와이프 → 이전 날짜
  - **편집 모드 중 스와이프 비활성** (데이터 유실 방지)
- 오브젝트 선택: 즉시 핸들 표시
- 저장: 저장 버튼 탭 시 즉시 완료 (진행 표시 없음, 완료 후 토스트)
- 외부 CDN 의존 목록: **Lucide Icons CDN** 1개만 사용. Noto Sans KR CDN 미사용 — 시스템 폰트 스택으로만 운영 (개발자가 임의로 CDN 폰트 추가 금지).
- 아이콘 CDN 실패 시: 텍스트 레이블로 대체 (예: ↩ / 펜 / 지우개 / T / 사진)
- 스와이프 원위치 애니메이션: ease-out 120ms
- 토스트 위치: 도구 모음 기준 16px 위 (편집 모드), 하단 바 기준 16px 위 (읽기 모드)
